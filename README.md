# 打卡助手（安卓）

给「八局通」这类没有自动打卡、也没有提醒功能的企业 app 用的半自动打卡工具。

原理：安卓无障碍服务（AccessibilityService）在本机前台读取界面，按文字找按钮并点击；AlarmManager 每天 08:10 / 17:30 唤醒。

用的是安卓公开的无障碍能力，和读屏软件同一套机制，不是注入、不是外挂。

## 能做什么

- 到点自动点亮屏幕、打开八局通，自动点：工作台 → 打卡 → 上班打卡
- **锁屏挂起**：到点如果屏幕锁着，任务挂起等解锁，一解锁立刻补打卡
- **任务有效期 30 分钟**，期间任何时刻解锁都能补上
- 手机重启后自动恢复定时
- **测试与诊断**：手动触发测试、「只诊断不点击」模式、实时日志

## 不能做什么

- 不能绕过定位校验
- 不能在你没解锁的情况下完成点击（页面在锁屏之上不响应）
- 界面改版后文字对不上就点不到，得改配置

## 构建（两种方式，选一种）

### 方式一：Android Studio

1. 装 Android Studio（自带 JDK 17）。
2. `File > Open` 选 `punch-assist` 目录。
3. 等 Gradle Sync。若提示缺 wrapper，执行 `gradle wrapper --gradle-version 8.7`，或在设置里把 `Use Gradle from` 指到本机 Gradle。
4. `Build > Build APK(s)`。
5. 产物在 `app/build/outputs/apk/debug/app-debug.apk`。

### 方式二：GitHub Actions

推到 GitHub，`.github/workflows/build.yml` 自动编译，去 Actions 下载 `apk` artifact。

## 手机上的配置

1. 装 APK，打开「打卡助手」。
2. ① 选择八局通应用（列表里显示应用名 + 包名）。
3. ② 打开无障碍设置，启用「打卡助手自动点击」。
4. ③ 允许后台弹出界面。
5. ④ 忽略电池优化。
6. 确认顶部四项全部正常。
7. 设上班 08:10、下班 17:30。
8. 点「测试上班打卡」。

## 测试与诊断

界面上有三样东西：

- **测试上班打卡 / 测试下班打卡**：立刻走一遍完整流程，不用等时间。
- **只诊断不点击**：勾上后跑测试，只会把界面上的文字写进日志，不点任何东西。用来对付"文字对不上"的情况：跑一次，看日志里 `诊断扫描：[...]` 打印的真实文字，把按钮文字改成那几个字。
- **日志**：每秒刷新，显示挂起、锁屏等待、找到按钮、点击结果、超时等。

## 锁屏挂起怎么工作

1. 08:10 闹钟到点，`AlarmReceiver` 点亮屏幕并写一个 30 分钟有效的挂起任务。
2. 如果当时屏幕锁着，`PunchLaunchActivity` 只亮屏提醒，不硬解；无障碍服务每秒检查一次，锁着就继续等，不消耗重试次数。
3. 你解锁的那一刻，`UnlockReceiver` 收到 `USER_PRESENT`，重新拉起八局通，服务接着点。
4. 成功或 30 分钟超时，任务清掉，结果写进日志和界面。

## 常见失败

| 现象 | 原因 | 处理 |
|---|---|---|
| 测试没反应 | 无障碍没开 | 确认服务是开启状态 |
| 到点不自动打开 | 后台弹出权限 / 电池优化 | ③④ 重做 |
| 打开八局通后不点 | 按钮文字不匹配 | 用「只诊断不点击」看日志，改文案 |
| 点了但没打上 | 定位不在范围 / 网络 | 考勤系统拦的，工具无能为力 |
| 解锁后没补上 | 任务已超 30 分钟 | 看日志，调大有效期或提前时间 |
| 点击落在错位置 | 页面被滚过 | 让八局通每次停在首页 |

## 风险

1. **企业微信同一账号只能一台手机在线**。安卓登录八局通，iPhone 上会被踢下线。
2. **代打卡违反考勤制度**，被查出来按公司规定处理。
3. 私有部署可能检测无障碍注入，检测到可能限制账号。
4. 个人实验工具，不保证在你公司部署上可用。

## 代码结构

```
app/src/main/java/com/diy/punch/
├── MainActivity.kt                 设置 + 测试 + 日志
├── Prefs.kt                        配置与任务状态
├── Diag.kt                         内存日志
├── AlarmScheduler.kt               每日定时
├── AlarmReceiver.kt                到点唤醒、挂起任务
├── UnlockReceiver.kt               解锁后补打卡
├── BootReceiver.kt                 重启后重排
├── PunchLaunchActivity.kt          透明页面，开八局通
├── PunchAccessibilityService.kt    找按钮、点击、锁屏等待
└── Notifier.kt                     兜底通知
```
